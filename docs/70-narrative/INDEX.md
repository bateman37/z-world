# 70-narrative — Narrativa procedural

## Responsabilidad

Define cómo el estado simulado del mundo genera situaciones narrativas
causales, y cómo se distingue información fiable de rumores.

## Qué pertenece aquí

- Flujo causal de generación de narrativa.
- Modelo de memoria y de información (hechos, rumores, falsedades) cuando se
  documenten.

## Qué no pertenece aquí

- El contenido concreto de situaciones o escenarios: `docs/scenarios/`.
- Reglas sociales que originan tensiones: `docs/50-society/`.
