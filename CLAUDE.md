# Instrucciones para Claude Code

Este archivo es deliberadamente corto. Las reglas completas están en
`AGENTS.md`; no las dupliques aquí.

Antes de trabajar:

1. Lee `AGENTS.md`.
2. Consulta `docs/INDEX.md` y `docs/STATUS.md`.
3. Lee únicamente el contexto obligatorio que declare el prompt de la tarea y
   sus dependencias relevantes; no expandas la lectura por defecto.
4. Usa búsquedas por identificador para localizar referencias antes de abrir
   documentos adicionales.
5. Al completar una entrega, actualiza la documentación afectada y
   `docs/STATUS.md` si cambió el estado real del proyecto.
6. Escribe toda la prosa en español, salvo identificadores, rutas y
   contratos técnicos (ver `AGENTS.md`).
