# Prompts

Todos los prompts de entrega, pasados y futuros, se guardan como archivos
Markdown en esta carpeta. `docs/` conserva las reglas; esta carpeta conserva
el historial de encargos.

## Protocolo de prompts futuros

Cada prompt futuro debe incluir, en este orden:

1. Identificador y título.
2. Contexto y precondiciones.
3. Lecturas obligatorias concretas por ruta o identificador.
4. Objetivo.
5. Alcance.
6. Fuera de alcance.
7. Reglas funcionales o técnicas específicas.
8. Documentación que debe actualizarse.
9. Validaciones y pruebas acotadas.
10. Criterios de aceptación.
11. Formato del informe final.

Los prompts deben enlazar las fuentes canónicas de `docs/` en lugar de
copiar toda su información. Un prompt representa una entrega coherente; no
debe expandirse con mejoras oportunistas durante su ejecución.
